# 自律习惯养成APP

这是一个基于uni-app x框架开发的自律习惯养成社交活动APP，帮助用户培养良好的生活习惯。

## 主要功能

### 1. 打卡系统
- **个人任务管理**：用户可以创建、编辑、删除个人打卡任务
- **公共任务**：系统提供的推荐任务，用户可以选择参与
- **任务设置**：
  - 任务名称（必填）
  - 每周频次（1-7次）
  - 任务描述（选填）
  - 是否允许补打卡
  - 任务标签选择（学习、家庭、健康等）
  - 主题色选择
  - 打卡提醒和提醒时间
- **打卡记录**：显示最近的打卡记录和统计信息

### 2. 导师系统
- **导师申请**：普通用户可以申请成为公益导师
- **导师列表**：显示所有通过审核的导师
- **导师详情**：查看导师信息和申请门槛
- **学员管理**：
  - 导师可以设定申请门槛（积分要求）
  - 导师可以给学员颁发毕业徽标
  - 同时只能绑定一个导师
  - 最多不能超过3个导师
  - 导师和学员都有资格解绑

### 3. 活动系统
- **活动列表**：显示线上和线下活动
- **活动详情**：查看活动信息、时间、地址等
- **活动报名**：用户可以报名参加活动
- **活动签到**：活动开始时出示二维码签到
- **参与门槛**：管理员可以设定积分或等级要求

### 4. 个人中心
- **用户数据**：显示积分、等级、打卡统计等
- **积分系统**：100积分=1星，1000积分=2星，10000积分=3星
- **数据统计**：总打卡数、连续天数、参与活动数等
- **功能菜单**：
  - 我的任务
  - 我的导师
  - 我的活动
  - 积分记录
  - 数据统计
  - 成就徽章
  - 邀请好友
  - 帮助反馈

## 技术架构

### 前端技术栈
- **框架**：uni-app x
- **语言**：UTS (类似TypeScript但类型更严格)
- **UI组件**：cool-ui
- **状态管理**：Vue 3 Composition API
- **路由**：uni-app路由系统

### 项目结构
```
├── pages/                 # 页面文件
│   ├── index/            # 主页面
│   │   ├── checkin.uvue  # 打卡页面
│   │   ├── mentor.uvue   # 导师页面
│   │   ├── activity.uvue # 活动页面
│   │   └── my.uvue      # 我的页面
│   ├── task/             # 任务相关页面
│   ├── mentor/           # 导师相关页面
│   ├── activity/         # 活动相关页面
│   └── stats/            # 统计页面
├── types/                # 类型定义
│   └── habit.ts         # 习惯养成相关类型
├── cool/                 # 核心功能
│   └── service/         # API服务层
│       └── habit.ts     # 习惯养成API
└── components/          # 组件
    └── tabbar.uvue      # 自定义底部导航
```

### API接口
- **认证相关**：登录、注册、重置密码
- **任务管理**：创建、编辑、删除、查询任务
- **打卡管理**：打卡、查询记录、统计
- **导师系统**：申请、绑定、解绑导师
- **活动管理**：报名、签到活动
- **用户中心**：个人信息、积分记录、数据统计

## 页面说明

### 主页面
1. **打卡页面** (`/pages/index/checkin`)：显示个人任务、公共任务、最近打卡记录
2. **导师页面** (`/pages/index/mentor`)：显示导师列表、我的导师状态
3. **活动页面** (`/pages/index/activity`)：显示活动列表、报名签到
4. **我的页面** (`/pages/index/my`)：显示用户数据、功能菜单

### 功能页面
- **任务管理** (`/pages/task/manage`)：管理个人任务
- **新增任务** (`/pages/task/add`)：创建新任务
- **导师列表** (`/pages/mentor/list`)：查看所有导师
- **活动详情** (`/pages/activity/detail`)：查看活动详情
- **数据统计** (`/pages/stats/index`)：查看详细统计

## 开发说明

### 环境要求
- HBuilderX 4.0+
- uni-app x 框架
- Node.js 16+

### 运行项目
1. 使用HBuilderX打开项目
2. 选择运行到iOS/Android设备
3. 或使用HBuilderX内置浏览器预览

### 注意事项
1. 所有页面都使用`.uvue`后缀
2. 严格遵循UTS语言规范
3. 使用条件编译处理平台差异
4. 可滚动内容必须放在滚动容器中
5. 页面需要在`pages.json`中注册

## 功能特色

1. **社交化**：导师学员系统，增加用户互动
2. **游戏化**：积分等级系统，提升用户粘性
3. **个性化**：自定义任务、主题色、提醒时间
4. **数据化**：详细的统计数据和进度跟踪
5. **活动化**：线上线下活动，丰富用户体验

这个APP通过任务打卡、导师指导、活动参与等方式，帮助用户建立良好的生活习惯，实现自我提升的目标。
